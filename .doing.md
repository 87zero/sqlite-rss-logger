sqlite-rss-logger is a public showcase project for the 87zero GitHub account. It provides
a Python logging handler that writes to one SQLite database per application, and a
FastAPI service that publishes the latest records from all of those databases as an
RSS feed. It installs from the GitHub URL with uv.
