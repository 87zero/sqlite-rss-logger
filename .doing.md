sqlite-rss-logger is a public showcase project in the 87zero GitHub account
(https://github.com/87zero/sqlite-rss-logger). It provides a Python logging handler that
writes to one SQLite database per application, and a FastAPI service that publishes the
latest records from all of those databases as an RSS feed. It installs from the GitHub URL
with uv (`uv add`, `uv tool install` or `uvx`).

Current state: version 0.2.0 is released and tagged. Open work is the feed reader
screenshot for the README and a decision on per-application feed URLs; see docs/TODO.md.
